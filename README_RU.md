# 📺 ShaGa IPTV Player

Лёгкий IPTV-плеер с открытым исходным кодом для устройств Roku, написанный на BrightScript и SceneGraph.

## Возможности

- 📺 Поддержка плейлистов M3U и M3U8
- ⚡ Быстрый и отзывчивый интерфейс
- 📂 Автоматическая группировка каналов по категориям
- 🔍 Поиск каналов
- 🖼️ Предпросмотр логотипов каналов
- ▶️ Встроенный мини-плеер
- 📡 Полноэкранное воспроизведение
- 💾 История последних плейлистов
- 🛠️ Открытый исходный код и возможность доработки

## Установка (Режим разработчика)

1. Скачайте репозиторий в виде ZIP-архива.
2. Включите Developer Mode на устройстве Roku.
3. Откройте IP-адрес Roku в браузере.
4. Загрузите ZIP через Roku Application Installer.
5. Запустите **ShaGa IPTV**.

## Сборка

Дополнительные инструменты не требуются.

Используются:

- BrightScript
- Roku SceneGraph (RSG)

Достаточно упаковать проект как Roku Channel.
